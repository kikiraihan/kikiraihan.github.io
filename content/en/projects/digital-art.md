A collection of personal illustration work.

Illustration is where I practise the things that later show up in interface and brand work: reducing a subject to the few shapes that make it recognisable, choosing a limited palette, and knowing when to stop rendering.

steps:
  - { title: Silhouette first, text: "Each piece starts from a pose that reads in solid black — if the silhouette works, the details are easy." }
  - { title: Limit the palette, text: "One dominant hue per piece (red, green, orange, blue) keeps the image calm and the subject clear." }
  - { title: Match finish to purpose, text: "Painting for a mood, vector for portraits that need to scale, flat shapes for a character that has to work small." }
