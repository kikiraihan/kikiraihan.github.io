## Problem

Students raising money for activities usually pass around a list of donors with little information about the activity itself. The idea: an alternative funding source that explains *what* is being funded.

## Solution

I built the interface from scratch with Bootstrap — no template — following mobile-first principles, since students mostly use their phones. See the [interface design case](/work/kongkong-interface) for the UI details.
